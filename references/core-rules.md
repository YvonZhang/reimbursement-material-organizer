# 通用整理规则

## 分类

默认分类：

- 酒店：住宿发票、酒店账单；入住证明、确认函和水单通常是辅助材料。
- 交通打车：网约车、出租车、接送机、租车及可确认的境外用车收据。
- 公共交通：地铁、公交、机场巴士、市域铁路及交通卡差旅记录。
- 机票：航空运输电子客票、机票订单与航司行程单。
- 火车票：铁路电子客票、高铁票和可核验的纸质票影像。
- 通讯费：差旅期间的漫游、通信套餐和必要通信支出。
- 餐费：公司规则允许时使用。
- 其它：无法归入以上类别但有明确报销依据的材料。

用户档案可以增加、重命名或禁用分类。只有存在有效计算项时才创建分类目录。

## 核验材料

对每份候选材料核对：

- 出行人或付款人；
- 日期与时间；
- 城市、起点和终点；
- 发票号、订单号、票号或行程编号；
- 金额、币种和税价合计；
- 它是主计算项、同组格式，还是辅助凭证。

不能只根据邮件主题、文件名或目录名确定归属。

## 金额优先级

1. 优先读取 XML 等结构化文件中的价税合计、票价或实付字段。
2. 再核对 PDF/OFD 中的小写金额、价税合计或行程合计。
3. 图片和截图只在内容清晰且能确认来源、日期与金额时计算。
4. 结构化文件与版式文件冲突时标为待复核，并记录冲突值。
5. 报销口径不明确时保留材料但不计入确定合计。

## 去重与辅助材料

综合使用发票号、订单号、票号、金额、日期、商户、路线和文件内容判断同组关系。

- 同一发票的 PDF、XML、OFD 只计算一次。
- 同一订单中的发票与行程单只计算一次，行程单写入主项备注。
- 酒店水单、入住证明、确认函通常辅助住宿发票，不另计金额。
- 同一订单包含不同服务时拆分计算，例如机票与接送机分别归类。
- 无法确认是否重复时保留两组材料，并将相关金额标为待复核。

## 币种

- CNY、HKD、USD、EUR 等币种分别小计。
- 不自行查询或采用汇率。
- 同时显示原币与人民币实付时，按用户或公司规则选择报销口径；另一金额写入备注。
- 用户提供汇率或换汇凭证时，记录原币、汇率、折算金额与凭证来源。

## 行程重建

逐日结合机票、火车票、住宿、本地交通和时间信息重建行程。主要城市默认按当天 12:00 所在地判断；证据不足时写明推断依据。

每日格式：

```text
YYYY-MM-DD 周X：主要城市：城市；行程：A → B 或本地行程；住宿：城市，酒店名/无
依据：用于判断的主要票据与时间点。
```

## 跨城检查

列出每一次城市或地区跳转：

- 已找到：写明日期、时间、起终点、车次或航班号、票据和金额。
- 疑似缺失：写明前后交通、住宿等推断依据，并给出建议补找位置。

本地打车、地铁和接送机可作为推断依据，但不能替代机票、火车票等主要跨城凭证。
